## 🚀 Features

- 🔒 **Message Encryption/Decryption** via password-based Fernet keys  
- 📁 **File Encryption/Decryption** with embedded salt  
- 🎨 **ASCII Banner** using `pyfiglet`  
- 🌈 **Colored Output** via `colorama`  
- 🧠 **No external dependencies** beyond listed packages
